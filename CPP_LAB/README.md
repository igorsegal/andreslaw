# Andreslav C++ Lab v0.1

Отдельная модульная C++17 лаборатория для анализа, симуляции и оптимизации. Исходный код v0.1 подготовлен и проверен локально (CMake build + CTest PASS). Канонический пакет содержится в архиве ANDRESLAW_CPP_LAB_v0_1.zip, который необходимо синхронизировать с данной веткой; текущий GitHub checkpoint пока содержит только архитектурные контракты.

Важно: реальный XFBAR reader, торговый эмулятор и оптимизатор НЕ РЕАЛИЗОВАНЫ. Нет предположений о бинарном формате или авторских формулах SWT.
