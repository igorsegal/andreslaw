# DATA-01 — XFBAR001 payload reader

## Подтверждённая часть формата
- magic `XFBAR001` (8 байт), версия 1 (uint32 little-endian после magic)
- фиксированный заголовок 60 байт + ASCII имя символа переменной длины
- запись 60 байт: time int64 (0), Open double (8), High (16), Low (24), Close (32), tick_volume int64 (40), spread int32 (48), real_volume int64 (52)
- little-endian, без padding

## Реализовано
- Чтение binary, проверка magic/version и указанного вызывающим символа
- Проверка длины и делимости полезного объёма на 60
- Проверка OHLC, монотонного времени, volume/spread, предохранитель max_records
- Отдельный декодер для каждой свечи, чтение только для чтения

## НЕ подтверждено — обязательная работа следующего блока
- Точное расположение и семантика полей заголовка: digits, point, timeframe, bar_count, first/last
- Сверка header_count с физическим количеством записей
- Время: секунда и часовой пояс/конвенция экспортёра
- Загрузка реального файла из `D:\AHexaTrader\1DataFiles\raw` и сравнение с эталонным C++ reader

Reader возвращает Ok только для payload контрактов. Это НЕ полная сертификация XFBAR. Тесты используют только синтетические файлы внутри test temporary path; рыночные данные оттуда запрещены.
