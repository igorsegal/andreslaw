## 2. AS-PATTERN-002
Полный Pattern не сводится к текущему совпадению направлений.
Авторские материалы отдельно описывают:
- паттерн разворота тренда;
- паттерн восстановления тренда;
- завершение коррекции;
- подтверждение младшими волнами;
- использование паттернов для открытия и закрытия сделок.
## 3. Важное архитектурное следствие
Полная Pattern logic должна быть state machine во времени.
Недостаточно знать только:
- current direction;
- current correction flag.
Нужно учитывать предыдущие состояния и переходы между ними.
## 4. Подтвержденный пример reversal
В авторском описании паттерна разворота используются, как минимум:
- изменение направления W4 в зоне экстремума;
- положение относительно диапазона/канала;
- переход W3 того же знака в другую полуплоскость;
- дополнительное подтверждение динамикой экстремумов.
Следовательно текущий AS_TrendState(direction, correction, valid)
может быть недостаточен для полной реализации reversal pattern.
## 5. Подтвержденный пример recovery
После отката старшего локального компонента
отслеживается восстановление исходного движения.
Практический пример автора:
- старшие тренды сохраняют общее направление;
- по дневному тренду произошел откат;
- после отката отслеживается паттерн разворота/восстановления
  дневного тренда в сторону общего движения;
- младший тренд используется как подтверждающий компонент.
