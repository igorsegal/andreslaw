## 2. AS-PATTERN-002
Полный Pattern не сводится к текущему совпадению направлений.
Авторские материалы отдельно описывают:
- паттерн разворота тренда;
- паттерн восстановления тренда;
- завершение коррекции;
- подтверждение младшими волнами;
- использование паттернов для открытия и закрытия сделок.
## 3. Важное архитектурное следствие
Полная Pattern logic должна быть state machine во времени.
Недостаточно знать только:
- current direction;
- current correction flag.
Нужно учитывать предыдущие состояния и переходы между ними.
## 4. Подтвержденный пример reversal
В авторском описании паттерна разворота используются, как минимум:
- изменение направления W4 в зоне экстремума;
- положение относительно диапазона/канала;
- переход W3 того же знака в другую полуплоскость;
- дополнительное подтверждение динамикой экстремумов.
Следовательно текущий AS_TrendState(direction, correction, valid)
может быть недостаточен для полной реализации reversal pattern.
## 5. Подтвержденный пример recovery
После отката старшего локального компонента
отслеживается восстановление исходного движения.
Практический пример автора:
- старшие тренды сохраняют общее направление;
- по дневному тренду произошел откат;
- после отката отслеживается паттерн разворота/восстановления
  дневного тренда в сторону общего движения;
- младший тренд используется как подтверждающий компонент.

### REVERSAL — доказанное ядро
Для паттерна разворота:
1. W4 находится в зоне локального максимума/минимума и меняет направление.
2. W3 имеет тот же знак и приближается к переходу через нулевую линию.
3. W2 уже пересекла нулевую линию в направлении формируемого разворота.
Дополнительное подтверждение:
динамика как минимум двух локальных экстремумов может подтверждать
направление W3 после разворота.
Продолжение сформированного reversal может привести к собственно
развороту тренда, когда W3 и W4 меняют знак.
### RECOVERY / CANCEL — доказанное ядро
Recovery является последующим состоянием относительно ранее
сформированного reversal-pattern.
Признаки:
1. ранее сформирован reversal-pattern;
2. W4 остается в исходной полуплоскости;
3. W2 и W3 возвращаются в исходную полуплоскость
   и/или W4 восстанавливает движение в исходном направлении.
Такой Pattern отменяет предыдущий сценарий разворота и восстанавливает
исходное движение.
### Масштаб Daily Pattern
Для дневного Pattern на графике M5:
- W4 = Daily;
- W3 = IDay;
- W2 = Hourly.
Это соответствует существующей структуре Andreslaw:
Daily / IDay / Hourly.
### Предварительная state machine
NEUTRAL
-> REVERSAL_CANDIDATE
-> REVERSAL_CONFIRMED
и альтернативный переход:
REVERSAL_CANDIDATE или REVERSAL_CONFIRMED
-> RECOVERY / REVERSAL_CANCELLED
### Что пока нельзя кодировать произвольно
Не определены численно:
- граница "зоны максимума/минимума";
- критерий W3 "близится к нулю";
- формальное окно первой/второй попытки W4;
- обязательность и точный алгоритм локальных экстремумов;
- точное участие SWTsr/SWTch в автоматической версии Pattern.
Числовые thresholds для этих условий не изобретать.
