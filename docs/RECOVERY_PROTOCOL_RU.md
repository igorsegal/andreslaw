# ANDRESLAW — протокол восстановления

## Исходная проблема

Перед восстановлением проект существовал в нескольких несовместимых копиях, часть include-файлов отсутствовала, часть модулей была заменена TODO/stub-реализациями, а главный Expert Advisor не компилировался.

## Принцип восстановления

1. Не исправлять каскадные ошибки по одной.
2. Восстановить зависимости и волновое ядро.
3. Использовать `AS_Waves` как единый источник волновой математики для EA, а не создавать второй независимый расчёт AS3.
4. Возвращать код из собственной истории проекта там, где он сохранился.
5. Сопоставлять восстановление с публичным описанием SWT.
6. Всё, что нельзя восстановить достоверно, помещать в `QUARANTINE`, а не додумывать.
7. До окончания проверки держать торговлю жёстко выключенной.

### Stage 6 — MTF Wave Provider

На первом шаге проверяются H1/D1/W1 как подтверждённые авторскими материалами временные контексты. Поля расширенной трендовой иерархии не получают произвольных timeframe без отдельного доказательства.
